# Spec-Driven Documents (SDD) — ROADMAP-TASKS

Every micro-task in [ROADMAP-TASKS.md](../../ROADMAP-TASKS.md) has a matching **SDD** in this folder.

## Format

| Section | Purpose |
|---------|---------|
| **Status** | `draft` (not built), `partial`, or `implemented` |
| **Problem / Goals / Non-goals** | Why and scope |
| **Behavior / Acceptance** | Normative for implementers (when code is involved) |
| **Related** | Specs, ADRs, runbooks elsewhere |

Older specs under `docs/specs/` remain valid; the SDD may **point** to them as the detailed source of truth (T012, T020, T022, T023).
